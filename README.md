# 📊 Sales & Profit Analysis Dashboard (Excel Project)

## 🧾 Project Overview

This project was created for **learning and practice purposes** to build hands-on experience in **data analysis and business intelligence using Microsoft Excel**.  
The goal of this project is to transform raw business data into meaningful insights through **data modeling, cleaning, and visualization**.

All data preparation, modeling, and visualization were performed entirely in **Microsoft Excel** using advanced features such as **Power Query**, **Power Pivot**, and **Excel Dashboards**.

---

## 🎯 Objectives

- Practice real-world **data cleaning & transformation**
- Build **data relationships** using Power Pivot
- Create an **interactive business dashboard**
- Generate insights on:
  - Sales performance  
  - Profitability  
  - Customer segments  
  - Product categories  
  - Shipment methods  
  - Regional performance

| **Slicers** | Interactive filtering |

---

## 🛠 Project Workflow

### 1️⃣ Data Cleaning & Preparation
- Imported raw datasets into **Power Query**
- Removed duplicates, handled missing values, and standardized data
- Loaded cleaned data into **Excel Data Model**

### 2️⃣ Data Modeling
- Created relationships between multiple tables using **Power Pivot**
- Built a structured data model for analysis

### 3️⃣ Analysis & Visualization
- Created Pivot Tables and charts from the data model
- Designed an interactive **Excel dashboard**
- Added slicers for dynamic filtering and exploration

---

## 📈 Key Features of the Dashboard

- 📦 **Shipment Mode Distribution**
- 🏆 **Top 5 Profitable States**
- 🏙️ **Top 10 Profitable Cities**
- ❌ **Top 3 Least Profitable Products**
- 👥 **Performance by Customer Segment**
- 🗂 **Profitability by Product Category**

All visuals are fully interactive using slicers.
